## 🌙 About

**Cat's Night**는 챕터 단위 진행을 목표로 개발 중인 2D Unity 프로젝트입니다.  
현재 저장소에는 게임 진행 제어, UI 관리, Scene 구성, Sprite 리소스와 Unity Input System 기반의 프로젝트 구조가 포함되어 있습니다.

## 🚧 Current Status

현재는 **초기 프로토타입 / 구조 설계 단계**입니다.

- 🎬 챕터 시작 입력 처리
- 🧭 챕터 이동 구조
- 🎮 GameController / GameManager 분리
- 🖥 UIManager 구성
- ⌨️ Unity Input System 적용
- 🎨 Sprite / Scene / URP 프로젝트 구조
